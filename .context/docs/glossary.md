# Glossary — Pulso de Mercado

- **Market Regime**: estado do mercado (STRONG RISK-ON … STRONG RISK-OFF).
- **Market Breadth**: 0–100 a partir de % acima SMA50/200, RSI>50,
  Supertrend bull, MACD bull.
- **Opportunity Score**: 0–100 ponderado (trend 20, momentum 20, RS 15,
  volume 15, RSI 10, MACD 10, volatilidade 5, regime 5).
- **Confidence**: confiança do sinal, separada do score.
- **Data Quality**: 0–100 (frescura, candles faltantes, profundidade).
- **Universo**: lista completa navegável (crypto ~17k, B3 ~400, EUA ~10k).
- **Stale**: dado servido do cache/snapshot após falha, sempre sinalizado.
- **Look-ahead bias**: proibido no backtest (sinal usa só dados até o timestamp).
